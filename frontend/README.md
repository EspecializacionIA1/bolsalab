# Frontend de BolsaLAB

App en Next.js que consume la API (`/api`). Se exporta como sitio estático y la sirve Caddy en `bolsa-lab.site`.

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```

`prototypes/` son los prototipos HTML anteriores; no forman parte de la app.
